# Roadmap

## Current slice

- Clean `app/ + sidecar/` layout.
- FastAPI endpoints compatible with the MVP workflow.
- React workbench for upload, profiling, inference, recommendation, execution, chat, and report generation.
- Electron shell that starts the local sidecar.

## Next milestones

- Real DID execution with fixed effects and clustered standard errors.
- RDD estimation with bandwidth selection and cutoff diagnostics.
- IV-2SLS execution with first-stage diagnostics.
- Persistent sessions for datasets, questions, model choices, and reports.
- Editable report export to Word or PDF.
- Better model-result diagnostics: VIF, missingness view, residual checks, and class-balance checks.
