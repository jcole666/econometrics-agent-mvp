# 小计使用文档

## 1. 打开软件

双击项目根目录的 `小计.exe`。启动后软件会自动拉起本地分析服务，第一次打开可能需要等待十几秒。

如果看到“后端服务在线”，说明本地分析服务已经准备好。

标题右侧有“工作台 / 字段画像 / 研究路径 / 分析报告”四个视图按钮。平时停留在“工作台”，需要看字段表、研究路径或报告时再点开对应按钮。

工作区支持拖动调整：左右列之间的竖条可以调列宽，每个板块底部的横条可以调当前板块高度；双击横条会恢复当前列的默认板块高度。右上角“演示布局”可以一键切回适合路演的布局。

## 2. 选择数据

支持的数据格式：

- CSV
- Excel xlsx
- Excel xls

选择数据有两种方式：

- 在左侧“数据”区域点击“选择”
- 在顶部菜单点击“文件” -> “选择数据文件”

选中文件后，左侧会显示文件名。然后点击“生成字段画像”，小计会读取字段名、类型、缺失值、唯一值和样例值，并给出样本量、缺失率、重复行、可能的时间列/个体列、面板结构和建模风险提示。

字段画像里的“关系线索”会列出数值变量之间较明显的相关关系，并用“变量关系地图”展示主要连接。左侧“数据体检”会把缺失、重复、异常值、关系线索和面板结构提到前面，适合路演时快速说明小计不是直接跑回归，而是先发现数据问题。它适合帮助你发现值得追问的方向，但不能直接当成因果结论。

如果是路演或课堂演示，可以点击左侧“演示”。它会加载城市面板样例，自动填好研究问题、Y、X、个体列和时间列，并继续生成模型推荐、运行面板固定效应和报告草稿。左侧会同步出现折叠的“样例场景”，展开后可以看到研究背景、识别路径和主要变量口径；下面还有“数据体检”“演示讲解卡”和“路演稿”，方便按数据场景、变量发现、模型路径、结果边界和收尾回应讲完整个流程。讲解卡下方的“评审追问”可以把常见问题放入右侧问答输入框，适合现场继续追问。

## 3. 填写研究问题

在“研究问题”里写清楚你想研究的关系。

示例：

```text
数字经济发展是否会提升城市创新水平？
```

建议写法：

- 说明被解释对象，例如收入、就业、消费、成绩
- 说明核心解释变量，例如教育、政策、价格、处理组
- 如果有控制变量，也写在问题里

## 4. 配置变量

字段画像生成后，可以手动填写变量，也可以点击“识别变量”让小计辅助判断。

常用字段：

- 被解释变量 Y：研究对象
- 解释变量 X：核心解释变量和控制变量
- 个体列：面板数据里的个体 ID
- 时间列：面板数据或 DID 里的年份、月份、日期
- 处理列：DID 里的处理组或政策变量
- 断点变量：RDD 里的 running variable
- 工具变量：IV-2SLS 里的 instrument

变量之间用英文逗号分隔。

## 5. 查看研究路径

字段画像生成后，点击标题右侧“研究路径”。这里会把当前数据结构、可追问的问题、变量设定、推荐方向、关键假设、风险边界和下一步判断整理成一条路径。可追问的问题可以直接“采用”为当前研究问题，也可以点“追问”放进右侧小计问答继续展开。

如果数据里有个体列和时间列，小计会优先提示可能的面板结构，例如城市 × 年份。这个模块适合在正式建模前确认：研究问题是否清楚、变量是否合理、结论能否被解释为因果。

研究路径下方有“协作检查点”。它不是自动替你决定结论，而是把研究问题、数据结构、变量设定、识别策略和风险边界拆成几个确认节点。每一项都可以勾选确认，也可以点击“去处理”回到对应位置继续调整。

“现场答辩卡”默认折叠在研究路径下方，展开后会看到因果边界、数据质量、人机协作和 Demo 价值几个常见追问。点击“放入问答”可以把对应问题放进右侧小计问答继续展开。

## 6. 推荐和运行模型

点击“推荐模型”，小计会根据研究问题、字段和变量配置推荐一个计量模型。

当前常用模型包括：

- OLS 线性回归
- Logit 二元选择模型
- 面板固定效应
- DID 双重差分
- RDD 断点回归
- IV-2SLS 工具变量

确认模型后，点击“运行模型”。运行结果会显示样本量、R2、核心变量解读、显著项、解释边界、系数、标准误、统计量和 p 值。

当前 OLS、Logit 和面板固定效应支持在软件内直接运行。DID、RDD 和 IV-2SLS 会先提供代码模板和检查清单，适合继续完善识别设计。

## 7. 建模问答

右侧“建模问答”可以继续追问：

- 为什么推荐这个模型？
- 系数应该怎么解释？
- 还需要检查哪些假设？
- 能不能加入交互项？
- 如何写论文里的模型设定部分？

发送问题时，小计会同时拿到当前字段列表、数据概览、变量配置、关系线索、研究路径、模型推荐和运行结果。因此建议先生成字段画像和模型推荐，再继续追问。

点击“新会话”可以开始新的对话。点击“历史对话”可以搜索和切换之前的对话。

## 8. 模型设置

右上角齿轮按钮用于配置大模型。

需要填写：

- 启用自定义模型
- 请求地址
- 模型名称
- API Key
- 超时秒数

配置只保存在当前电脑，不会写进代码。

如果没有配置 API Key 或请求地址，问答会提示你先补全模型配置。

## 9. 生成报告

点击标题右侧“分析报告”，再点击“生成报告”，页面会显示 Markdown 格式的分析报告。

报告会汇总研究问题、模型选择、核心结果、建模提醒，以及当前字段画像里的数据概览、关系线索、研究路径和风险边界。已经运行模型时，核心结果会先解释核心变量方向、显著项和解释边界，再附完整系数表；没有运行模型时，报告会保留“当前还没有模型运行结果”的提示，适合先作为方案草稿。

报告可以导出为：

- MD：适合继续编辑
- PDF：适合提交或发送

导出按钮在“分析报告”区域上方。

## 10. 常见问题

### 后端服务离线

先关闭软件，再重新双击 `小计.exe`。如果仍然失败，检查是否已有另一个小计窗口正在运行。

### 端口被占用

小计默认使用本地端口 `8768`。如果提示端口被占用，关闭其他正在运行的小计实例后再打开。

### Excel 读取失败

确认文件没有被 Excel 占用，并检查表头是否在第一行。

### 模型回答不出来

检查右上角模型设置里的 API Key、请求地址和模型名称是否正确。

### 运行模型失败

常见原因包括：

- 数据行数太少
- 变量名写错
- 某些变量不是数值型
- 缺失值过多
- 分类变量没有正确处理

可以先看字段画像，再调整变量配置。
