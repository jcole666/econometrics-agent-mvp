# 小计使用文档

## 1. 打开软件

双击项目根目录的 `小计.exe`。启动后软件会自动拉起本地分析服务，第一次打开可能需要等待十几秒。

如果看到“后端服务在线”，说明本地分析服务已经准备好。

## 2. 选择数据

支持的数据格式：

- CSV
- Excel xlsx
- Excel xls

选择数据有两种方式：

- 在左侧“数据”区域点击“选择”
- 在顶部菜单点击“文件” -> “选择数据文件”

选中文件后，左侧会显示文件名。然后点击“生成字段画像”，小计会读取字段名、类型、缺失值、唯一值和样例值。

## 3. 填写研究问题

在“研究问题”里写清楚你想研究的关系。

示例：

```text
数字经济发展是否会提升城市创新水平？
```

建议写法：

- 说明被解释对象，例如收入、就业、消费、成绩
- 说明核心解释变量，例如教育、政策、价格、处理组
- 如果有控制变量，也写在问题里

## 4. 配置变量

字段画像生成后，可以手动填写变量，也可以点击“识别变量”让小计辅助判断。

常用字段：

- 被解释变量 Y：研究对象
- 解释变量 X：核心解释变量和控制变量
- 个体列：面板数据里的个体 ID
- 时间列：面板数据或 DID 里的年份、月份、日期
- 处理列：DID 里的处理组或政策变量
- 断点变量：RDD 里的 running variable
- 工具变量：IV-2SLS 里的 instrument

变量之间用英文逗号分隔。

## 5. 推荐和运行模型

点击“推荐模型”，小计会根据研究问题、字段和变量配置推荐一个计量模型。

当前常用模型包括：

- OLS 线性回归
- Logit 二元选择模型
- 面板固定效应
- DID 双重差分
- RDD 断点回归
- IV-2SLS 工具变量

确认模型后，点击“运行模型”。运行结果会显示样本量、R2、系数、标准误、统计量和 p 值。

## 6. 建模问答

右侧“建模问答”可以继续追问：

- 为什么推荐这个模型？
- 系数应该怎么解释？
- 还需要检查哪些假设？
- 能不能加入交互项？
- 如何写论文里的模型设定部分？

点击“新会话”可以开始新的对话。点击“历史对话”可以搜索和切换之前的对话。

## 7. 模型设置

右上角齿轮按钮用于配置大模型。

需要填写：

- 启用自定义模型
- 请求地址
- 模型名称
- API Key
- 超时秒数

配置只保存在当前电脑，不会写进代码。

如果没有配置 API Key 或请求地址，问答会提示你先补全模型配置。

## 8. 生成报告

点击“生成报告”后，右侧会显示 Markdown 格式的分析报告。

报告可以导出为：

- MD：适合继续编辑
- PDF：适合提交或发送

导出按钮在“分析报告”区域上方。

## 9. 常见问题

### 后端服务离线

先关闭软件，再重新双击 `小计.exe`。如果仍然失败，检查是否已有另一个小计窗口正在运行。

### 端口被占用

小计默认使用本地端口 `8768`。如果提示端口被占用，关闭其他正在运行的小计实例后再打开。

### Excel 读取失败

确认文件没有被 Excel 占用，并检查表头是否在第一行。

### 模型回答不出来

检查右上角模型设置里的 API Key、请求地址和模型名称是否正确。

### 运行模型失败

常见原因包括：

- 数据行数太少
- 变量名写错
- 某些变量不是数值型
- 缺失值过多
- 分类变量没有正确处理

可以先看字段画像，再调整变量配置。
