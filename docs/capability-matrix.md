# 能力矩阵（唯一事实来源）

本文件记录当前版本**真实具备**的能力，用于对齐 README、中期材料与界面提示。任何面向用户的宣称都以此为准；此处没有写的能力即为未实现。

版本：v0.7.0 · 更新日期：2026-11-06

## 一、计量模型

| 模型 | 是否真实估计 | 实现位置 | 说明 |
|---|---|---|---|
| OLS | 是 | `sidecar/services/model_runner.py` `_run_ols` | HC1 稳健标准误；自动剔除缺失与非数值行 |
| Logit | 是 | `_run_logit` | 要求 Y 为 0/1，否则报业务错误 |
| 面板双向固定效应 | 是 | `_run_panel_fixed_effects` | 个体 + 时间固定效应，按个体聚类稳健标准误（linearmodels） |
| DID | 否，仅代码模板 | `sidecar/services/code_generator.py` | 模板已按「年份 → 0/1 post × 0/1 处理组」生成交互项；政策年份需填写 |
| RDD | 否，仅代码模板 | 同上 | 模板为局部线性、按带宽筛样本；断点/带宽可传入，缺省带宽取 running 列标准差 |
| IV-2SLS | 否，仅代码模板 | 同上 | 模板用 linearmodels.IV2SLS；列名含空格需先改名 |

接口行为：`/run-model` 返回 `execution_status`。
- `executed`：已真实估计，`results` 有系数、标准误、p 值、置信区间、样本量。
- `planned`：未估计，`results` 为空，`code_template` 给出可运行模板，`error` 说明原因。

## 五、维护约定

1. 新增能力先改本文件，再改 README 与中期材料，避免文档跑在代码前面。
2. 界面上的措辞与 `execution_status` 保持一致：未真实估计的模型不得显示「结果」。
3. 涉及统计结论的文案，数值只能来自后端计算结果，不得由大模型生成。
