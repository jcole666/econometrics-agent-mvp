## Demo 视频建议流程

1. 展示项目首页或 API 文档；
2. 上传 `examples/sample_wage.csv`；
3. 展示系统识别出的字段信息；
4. 输入研究问题：教育水平和工作经验是否影响收入；
5. 展示推荐模型 OLS；
6. 展示生成的 Python 代码；
7. 再输入一个 DID/RDD/IV 示例，展示复杂模型的检查清单和代码模板。
